# NewLife.Omron FINS 协议功能分析报告

## 1. 项目概述

NewLife.Omron 是基于 NewLife 组件生态的欧姆龙 PLC FINS 协议实现库。

| 项目 | 说明 |
|------|------|
| NuGet 包名 | `NewLife.Omron` |
| 版本号规则 | `1.1.yyyy.MMdd` |
| 目标框架 | `net45` / `net461` / `netstandard2.0` / `netstandard2.1` |
| C# 版本 | `latest` |
| 外部依赖 | `NewLife.IoT 2.7.2026.201` / `Microsoft.SourceLink.GitHub 10.0.103` |
| 授权协议 | MIT |
| 仓库地址 | https://github.com/NewLifeX/NewLife.Omron |

当前已实现 FINS/TCP、FINS/UDP、HostLink 三种协议的完整同步+异步读写功能、设备管理以及丰富的类型化 API。

## 2. 项目结构

### 2.1 源码目录

```
NewLife.Omron/
├── Protocols/                   # 协议层（核心）
│   ├── FinsClient.cs            # FINS/TCP 客户端（同步）
│   ├── FinsClient.Async.cs      # FINS/TCP 客户端（异步，partial）
│   ├── FinsUdpClient.cs         # FINS/UDP 客户端（同步）
│   ├── FinsUdpClient.Async.cs   # FINS/UDP 客户端（异步，partial）
│   ├── HostLinkClient.cs        # HostLink C-mode 客户端（同步）
│   ├── HostLinkClient.Async.cs  # HostLink C-mode 客户端（异步，partial）
│   ├── FinsServer.cs            # FINS/TCP 模拟服务器（用于开发测试）
│   ├── HostLinkMessage.cs       # HostLink 帧编码/解码 + FCS 校验

│   ├── FinsHeader.cs            # FINS 帧头（10 字节路由头）
│   ├── FinsCommand.cs           # FINS 命令码常量定义（MRC:SRC）
│   ├── FinsAddress.cs           # 地址字符串解析（D100, CIO200.5 等）
│   ├── MemoryArea.cs            # 存储区枚举 + 辅助方法
│   ├── ByteTransform.cs         # 字节序转换（ABCD/BADC/CDAB/DCBA）
│   ├── DataFormat.cs            # 字节序格式枚举
│   ├── CpuUnitData.cs           # CPU 型号/版本数据模型
│   └── CpuUnitStatus.cs         # CPU 运行状态/错误数据模型 + CpuMode 枚举
├── Drivers/                     # IoT 驱动层
│   ├── OmronDriver.cs           # DriverBase 实现，[Driver("OmronPLC")]
│   ├── OmronNode.cs             # INode 实现
│   └── OmronParameter.cs        # IDriverParameter 实现
```

### 2.3 类关系

```
FinsClient (FINS/TCP)
├── FinsMessage           ← 消息构建/解析

│   ├── FinsCommand       ← MRC:SRC 命令码

├── FinsHeader / FinsCommand  ← 帧解析（共用）
├── MemoryAreaHelper      ← 位/字区域判断
├── FinsMessage           ← BCD 编解码（共用）
└── CpuMode               ← CPU 状态模拟

FinsUdpClient (FINS/UDP)
├── FinsMessage / FinsAddress / ByteTransform（共用）
└── UdpClient（无握手直连）

HostLinkClient (HostLink C-mode)
├── HostLinkMessage       ← C-mode 帧编码/解码 + FCS
├── FinsAddress           ← 地址解析（共用）
├── FinsMessage           ← FINS 网关命令（FA）
└── ByteTransform         ← 类型化读写转换（共用）

OmronDriver (IoT 平台)
├── FinsClient            ← 底层通信
├── OmronNode             ← INode
└── OmronParameter        ← IDriverParameter
```

### 3.3 存储区支持

MemoryArea 枚举及 FinsAddress 地址解析支持以下存储区：

| 存储区 | 字代码 | 位代码 | 地址前缀 | 说明 |
|--------|--------|--------|----------|------|
| CIO | 0xB0 | 0x30 | CIO / C | Core I/O 区 |
| WR | 0xB1 | 0x31 | WR / W | Work Area |
| HR | 0xB2 | 0x32 | HR / H | Holding Area |
| AR | 0xB3 | 0x33 | AR / A | Auxiliary Area |
| DM | 0x82 | 0x02 | DM / D | Data Memory |
| EM0~EM3 | 0xA0~0xA3 | 0x20~0x23 | EM0:~EM3: | 扩展数据存储器多 Bank |
| EM 当前Bank | 0x98 | — | EM | 扩展数据存储器当前 Bank |
| TIM/CNT (PV) | 0x89 | — | TIM / CNT | 定时器/计数器当前值 |
| TIM/CNT (状态) | — | 0x09 | — | 定时器/计数器完成标志 |
| IR (索引寄存器) | 0xDC | — | IR | Index Register |
| DR (数据寄存器) | 0xBC | — | DR | Data Register |
| Task Flag | — | 0x46 | — | 任务标志（仅位访问） |

地址格式示例：`D100`、`CIO200.5`、`W100`、`H10`、`EM0:100`、`TIM5`、`CNT3`、`IR0`、`DR0`

### 3.4 类型化 API

三个客户端（FinsClient / FinsUdpClient / HostLinkClient）均提供同步 + 异步类型化 API：

| 类型 | 同步读/写 | 异步读/写 | 字数 |
|------|-----------|-----------|------|
| Int16 | ReadInt16 / WriteInt16 | ReadInt16Async / WriteInt16Async | 1 |
| UInt16 | ReadUInt16 / WriteUInt16 | ReadUInt16Async / WriteUInt16Async | 1 |
| Int32 | ReadInt32 / WriteInt32 | ReadInt32Async / WriteInt32Async | 2 |
| UInt32 | ReadUInt32 / WriteUInt32 | ReadUInt32Async / WriteUInt32Async | 2 |
| Int64 | ReadInt64 / WriteInt64 | ReadInt64Async / WriteInt64Async | 4 |
| UInt64 | ReadUInt64 / WriteUInt64 | ReadUInt64Async / WriteUInt64Async | 4 |
| Single | ReadFloat / WriteFloat | ReadFloatAsync / WriteFloatAsync | 2 |
| Double | ReadDouble / WriteDouble | ReadDoubleAsync / WriteDoubleAsync | 4 |
| String | ReadString / WriteString | ReadStringAsync / WriteStringAsync | N |
| Boolean | ReadBool / WriteBool | ReadBoolAsync / WriteBoolAsync | 位操作 |
| Byte[] | ReadBit / WriteBit | ReadBitAsync / WriteBitAsync | 位操作 |

> 三个客户端（FinsClient / FinsUdpClient / HostLinkClient）均提供完整的同步 + 异步类型化 API，包括 Int64/UInt64。

### 3.5 字节序转换

ByteTransform 类支持四种字节序格式（DataFormat 枚举）：

| 格式 | 说明 | 16 位字节序 | 32 位字节序 |
|------|------|-------------|-------------|
| ABCD | 标准大端 | [H, L] | [HH, HL, LH, LL] |
| BADC | 字内交换 | [L, H] | [HL, HH, LL, LH] |
| CDAB | 双字交换（欧姆龙默认） | [H, L] | [LH, LL, HH, HL] |
| DCBA | 标准小端 | [L, H] | [LL, LH, HL, HH] |

支持类型：Int16、UInt16、Int32、UInt32、Int64、UInt64、Single、Double、Boolean、String。

### 3.6 通信增强

| 功能 | 客户端 | 说明 |
|------|--------|------|
| 自动重连 | FinsClient | AutoReconnect(默认 true) + MaxReconnectRetries(默认 3) |
| 退避重试 | FinsClient | 重连间隔随重试次数递增 (1s, 2s, 3s) |
| 连接错误检测 | FinsClient | 识别 IOException / SocketException / TimeoutException |
| 批量读取 | FinsClient | BatchRead — 自动合并同区域相邻/重叠地址减少通信次数 |
| 线程安全 | 全部 | 同步方法使用 lock，异步方法使用 SemaphoreSlim(1,1) |
| 节点地址自动推导 | FinsUdpClient | 从 IP 地址最后一段自动设置源/目标节点地址 |

### 3.7 异步 API

通过 Partial Class 将异步方法分离到独立文件（*.Async.cs），不影响同步 API：

| 客户端 | 异步文件 | 主要异步方法 |
|--------|----------|-------------|
| FinsClient | FinsClient.Async.cs | ConnectAsync + 全部存储区/设备操作/类型化 API (45+ 方法) |
| FinsUdpClient | FinsUdpClient.Async.cs | ReadAsync/WriteAsync + ReadBitAsync/WriteBitAsync + 类型化 API |
| HostLinkClient | HostLinkClient.Async.cs | ReadAsync/WriteAsync + SendFinsCommandAsync + 类型化 API |

实现要点：
- 库内部全部使用 `ConfigureAwait(false)` 避免死锁
- FinsClient 异步连接使用 `Task.Factory.FromAsync` 兼容 net45+
- FinsClient 异步读取使用 `CancellationTokenSource(timeout)` 实现超时
- FinsClient SendAndReceiveAsync 包含完整的异步自动重连+退避逻辑

### 3.8 HostLink 协议

| 功能 | C-mode 命令 | 说明 |
|------|-------------|------|
| CIO 读写 | RR / WR | Core I/O + Work Area |
| DM 读写 | RD / WD | Data Memory |
| HR 读写 | RH / WH | Holding Area |
| AR 读写 | RJ / WJ | Auxiliary Area |
| TIM/CNT 读写 | RC / WC | 定时器/计数器 PV |
| EM 读写 | RE / WE | 扩展数据存储器 |
| CPU 状态 | SC | 读取/切换运行模式 |
| 通信测试 | TS | 回环测试 |
| FINS 网关 | FA | 通过 HostLink 发送任意 FINS 命令 |

传输方式：Stream 抽象（支持串口流 / 网络流），另有 TCP 直连构造函数。

### 3.9 IoT 平台集成

| 类 | 基类/接口 | 说明 |
|----|-----------|------|
| OmronDriver | DriverBase | [Driver("OmronPLC")] 标记，实现 Open/Close/Read/Write |
| OmronNode | INode | 存储地址、驱动引用、设备引用 |
| OmronParameter | IDriverParameter | Address(ip:port)、DA2(单元号)、DataFormat |

驱动特性：
- 多通道共享连接：多个 OmronNode 共享同一 FinsClient TCP 连接，引用计数管理生命周期
- 自动类型转换写入：支持 Int16~UInt64 / Single / Double / String / Boolean / Byte[] 写入
- 点位地址支持冒号分隔的位域（自动截取冒号前部分）

### 3.10 数据模型

| 类 | 对应 FINS 命令 | 字段 |
|----|----------------|------|
| CpuUnitData | 05:01 Controller Data Read | Model / Version / SystemVersion / AreaDataCapacity / ProgramCapacity / IomSize / DmCapacity / TimerCounterCount / EmBankCount |
| CpuUnitStatus | 06:01 Controller Status Read | Mode(CpuMode 枚举) / FatalError / NonFatalError / FatalErrorData / NonFatalErrorData / MessageFlags |
| CpuMode 枚举 | — | Program(0x00) / Debug(0x01) / Monitor(0x02) / Run(0x04) |

### 3.11 FINS/TCP 模拟服务器

FinsServer 类模拟欧姆龙 PLC 的 FINS/TCP 协议通信，用于开发调试和单元测试。

| 功能 | 说明 |
|------|------|
| TCP 监听 | TcpListener + 后台任务，支持随机端口（port=0） |
| FINS/TCP 握手 | 自动分配客户端节点地址，返回服务端节点地址 |
| 存储区模拟 | 支持全部字/位区域（DM/CIO/WR/HR/AR/EM/TIM/CNT）的读写 |
| 命令处理 | 存储区读写/填充/传送/多区域读取 + CPU 控制 + 时钟 + 设备信息等 27 种命令 |
| 内存辅助 | ReadMemory/WriteMemory 公共方法，方便测试中预设/验证数据 |
| CPU 模拟 | CpuMode / CpuModel / CpuVersion 属性可配置 |
| 时钟模拟 | Clock 属性可覆盖，默认返回系统时间 |
| 线程安全 | 全部存储区操作使用 lock 保护 |
| 多客户端 | 每个客户端连接独立后台任务处理 |
