# NewLife.Omron 需求文档

**项目**：NewLife.Omron — 欧姆龙 PLC 通信协议库  
**版本**：v1.1  
**日期**：2026-05-14  
**状态**：正式发布，全部功能模块已完成

---

## 1. 项目愿景与目标

### 1.1 愿景

做一个**纯 .NET 实现、零第三方依赖**的欧姆龙 PLC 通信协议库，让工业开发者用几行代码就能与欧姆龙设备通信，无需深入了解 FINS 协议细节，同时与 NewLife IoT 生态无缝集成。

### 1.2 目标

| 维度 | 目标描述 |
|------|----------|
| **协议完整性** | 完整实现 FINS/TCP、FINS/UDP、HostLink C-mode 三种协议，覆盖 FINS 全部 27 种命令 |
| **零门槛使用** | 提供类型化高级 API（ReadInt16/WriteFloat 等），开发者不需要了解 FINS 帧结构 |
| **IoT 平台集成** | 实现 NewLife.IoT 标准驱动接口，可直接接入星尘（Stardust）分布式平台和 IoTEdge 网关 |
| **工程品质** | 零第三方依赖，多框架支持（net45~netstandard2.1），完整单元测试覆盖 |
| **开发友好** | 提供 FinsServer 模拟服务器，无需真实 PLC 即可开发和测试 |

---

## 2. 目标用户与应用场景

### 2.1 目标用户

- **工业自动化系统开发者**：对接欧姆龙 PLC 实现 SCADA、上位机、MES 系统
- **IoT 边缘网关开发者**：嵌入到边缘计算设备，实现 PLC 数据采集上云
- **数据采集工程师**：需要从欧姆龙 PLC 读取生产数据做分析的工程师
- **工业软件集成商**：将欧姆龙设备数据集成到第三方系统（ERP/数仓等）

### 2.2 典型应用场景

| 场景 | 使用方式 |
|------|----------|
| **实时数据采集** | 使用 FINS/TCP 或 FINS/UDP 高频轮询 PLC 存储区，采集生产参数 |
| **设备监控与告警** | 读取 CPU 运行状态、错误日志，实现设备健康监控 |
| **远程控制** | 向 PLC 写入数据，实现远程参数下发和设备控制 |
| **老设备串口接入** | 使用 HostLink 协议通过 RS-232C/422/485 接入老型号欧姆龙 PLC |
| **IoT 平台网关** | 通过 OmronDriver 驱动接口，集成进 NewLife IoTEdge 实现统一设备管理 |
| **离线开发与测试** | 使用 FinsServer 模拟 PLC，无需硬件设备即可完成开发和自动化测试 |

## 3. 核心设计理念

| 理念 | 说明 |
|------|------|
| **零依赖** | 协议层仅依赖 .NET BCL（Socket/Stream），无第三方运行时依赖，可在任何 .NET 环境使用 |
| **完整覆盖** | FINS 协议 27 种命令、14 种存储区、4 种字节序，一个库解决全部需求 |
| **分层清晰** | 传输层 → 协议层 → 类型层 → 驱动层，每层职责单一，方便扩展 |
| **同步 + 异步** | 所有 API 均提供同步和 Async 版本，支持异步编程模型 |
| **IoT 标准** | 实现 NewLife.IoT 的 DriverBase 接口，与 NewLife 生态各平台无缝集成 |
| **测试保障** | 全部功能模块均有单元测试覆盖，214 个测试全部通过 |

## 5. 非功能性需求

### 5.1 性能

- **批量读取**：同一区域内的相邻地址自动合并为一次 FINS 请求，减少网络往返次数
- **长连接**：TCP 连接保持，避免每次操作都重新建立连接
- **异步非阻塞**：全部 API 提供异步版本，支持高并发访问场景

### 5.2 可靠性

- **超时控制**：`ReceiveTimeout` 可配置（默认 3000ms），防止无响应永久阻塞
- **自动重连**：FINS/TCP 检测到连接断开时自动重连，重试间隔 1s→2s→3s，最大 3 次
- **线程安全**：同步 API 使用 `lock` 互斥，异步 API 使用 `SemaphoreSlim(1,1)`

### 5.3 兼容性

- **协议兼容**：严格遵循欧姆龙 FINS 协议规范和 HostLink C-mode 规范
- **框架兼容**：支持从 .NET Framework 4.5 到 .NET 9.0 的全部主流版本
- **设备兼容**：兼容欧姆龙 CP/CJ/CS/NJ/NX 系列 PLC 及支持 FINS 的第三方设备

### 5.4 可维护性

- **分层架构**：传输/协议/类型/驱动四层分离，每层可独立替换和测试
- **测试覆盖**：214 个单元测试，覆盖全部协议层逻辑
- **无依赖**：协议层仅依赖 .NET BCL，无第三方依赖引入的维护负担
